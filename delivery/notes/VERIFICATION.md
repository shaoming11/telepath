## Test boundaries

Physical AirPods, iPhones, a venue projector, the venue hotspot and live transcription or voice-cloning providers require a room rehearsal. Browser playback confirmation reports that playback started. It cannot establish that a physical listener heard the whisper.

The package includes the locked document-parser binaries for Windows x64, Apple Silicon, Intel Mac and Linux x64 with glibc. Windows and Linux ran the packaged hub and parsed synthetic documents. The two macOS binaries were checked against their lockfile hashes and processor architectures. A physical Mac was unavailable. The Wasp development project uses SQLite and the local hub owns session state. Wasp’s standard server deployment profile requires PostgreSQL.
