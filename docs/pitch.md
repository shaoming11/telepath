# Telepathy pitch cue sheet

**A presents. B coaches from the audience. A third person runs the MacBook.** Open the stage locally, keep the MacBook lid open and the deck on the projector, and press **O** to open Operator.

## Before the pitch

1. Join A and B from the same hotspot. Leave both browser windows open and the phones awake.
2. After consent, record each person’s 30-second reading. Check that both seats show the expected voice and that the stage reports **Transcribing** for each physical seat. If setup is running late, choose **Use the premade voice** on that phone. A configured presenter clone takes priority over the bundled rehearsal voice.
3. Set AirPods right to Next Track and left to Previous Track. Test both sides and run calibration. If a headset sends no callbacks, keep the phone’s Live touch buttons within reach.
4. Choose **Sound check** in Operator and send it. Confirm the panel reports playback on both seats. Ask both people to give a visible nod before starting.
5. Start the session on the MacBook. Return the projector to the deck.

## Run it

| Beat | Presenter A | Coach B | MacBook operator |
| --- | --- | --- | --- |
| Hook | “What if your teammate could steer your pitch without interrupting it?” | Watch the timer. | Keep the deck up. |
| Fixed whisper | Speed up slightly, then slow down when the whisper arrives. Reply with R1 after hearing it. | R1 sends **Slow down**. Listen for the receipt. | Check that the Live board logs a playback start and a receipt. |
| Time cue | Move from setup into the live exchange. | R2 sends **One minute left**. | Near the wrap, use **Thirty seconds left** if both people need the same cue. |
| Smart draft | Continue speaking until the partner’s confirmed line arrives. | Report an actual observation and use L-R to request a draft. During rehearsal, say “The judge on the left looks lost.” Wait for the preview, then R1 to send. | If the draft times out, keep going with the fixed cues. The canned take shows the full preview-and-confirm sequence. |
| Wrap | End the pitch on the Out whisper. | Remove an earbud or use the Out button to send **Wrap it up now**. | After playback, choose **Reveal** and put the stage on the projector. |

Point to the four whispers and the **7 bits** in the rehearsed example. Each of its three fixed selects used two bits. The draft approval used one. Receipts and operator announcements add zero. The timeline shows the actual messages sent in this run, so the count can differ.

## Recovery

- A seat goes offline. Check its phone and let it rejoin; fixed messages resume once its cache is ready. The announcement panel reports a partial result if only one seat confirms playback.
- Bluetooth taps stop. The affected person uses the same named signals on Live. Keep Bluetooth output paired and continue with cached audio.
- Both seats lose audio or the provider blocks the demo. Open **Canned take**. In about 18 seconds it replays the complete pitch, including the private preview, approval, receipt and Reveal, through the MacBook’s speakers.
