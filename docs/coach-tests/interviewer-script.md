# Interviewer script for the test

For your friend to read. This file is not for uploading. The coach should help with each question using the persona docs.

1. Tell me about yourself.
2. Walk me through the hardest technical problem you've worked on.
3. Tell me about a time you failed.
4. Tell me about a time you disagreed with a senior engineer.
5. What's your biggest weakness?
6. What did you actually build on Telepathy?
7. Why should we hire you over someone with more experience?
8. Do you have any questions for me?

Curveballs to see if the coach stays honest. Nothing in the docs covers these, so the coach should stay quiet or suggest a clarifying question:

- What's your experience with Kubernetes in production?
- What's your favourite sorting algorithm and why?
